# The Homelab Postmortem

Source for [thehomelabpostmortem site] — real, dated postmortems from
running a homelab, and the scripts that came out of them.

Built with Jekyll, hosted on GitHub Pages. Posts live in `_posts/`, static
pages in the repo root.

Toolkit scripts referenced in posts are not stored in this repo — see the
`/toolkit/` page on the live site.
